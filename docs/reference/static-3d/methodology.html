Methodology

Every calculation is a small, published formula. The same code runs in your browser and in our automated tests.

3D Print Cost Calculator

material = grams ÷ spool grams × spool price
electricity = watts ÷ 1000 × hours × (¢/kWh ÷ 100)
machine = hours × (printer price ÷ lifetime hours + maintenance/hour)
failure allowance = run cost ÷ (1 − failure rate) − run cost
price = (total cost + fixed fees) ÷ (1 − margin − fee %)
